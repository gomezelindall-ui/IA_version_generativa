# Cómo contribuir a ELIN

¡Gracias por tu interés! Para colaborar:

1. Haz un *fork* del repositorio y crea una rama: `git checkout -b mi-mejora`
2. Instala las dependencias: `pip install -r requirements.txt`
3. Realiza tus cambios y pruébalos con `python elin.py`
4. Haz commit con un mensaje claro: `git commit -m "Añade ..."`
5. Sube tu rama y abre un *Pull Request* describiendo qué cambia y por qué.

## Reportar errores

Abre un *issue* con: sistema operativo, versión de Python, pasos para reproducir
y el mensaje de error completo.

## Seguridad

Nunca incluyas claves de API ni tokens en commits, issues o Pull Requests.
