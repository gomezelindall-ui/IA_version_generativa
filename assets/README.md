# assets

Carpeta opcional para los iconos de los botones de ELIN.

Si colocas aquí un PNG con el nombre de un botón (por ejemplo `chat.png`, `create.png`,
`search.png`, `download.png`, `trash.png`, `logo.png`…), ELIN lo dibuja sobre el mosaico
de color. Si no existe, usa un gradiente con una letra o icono por defecto.
